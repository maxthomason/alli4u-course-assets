Media Operations

Client-Isolated Media Trafficker Layout

For media traffickers managing multiple ad accounts, grouping 01_knowledge_base and planning directly inside each client folder under projects/ guarantees that account-specific targeting boundaries and campaign naming specs remain isolated during social trafficking.

"What lives in the client directory shapes everything the agent can do. Isolating rules per client folder prevents cross-contamination across ad accounts."
